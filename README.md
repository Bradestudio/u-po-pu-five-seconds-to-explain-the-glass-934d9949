One sentence a house cat would say in its own defence, five seconds after sweeping a glass off the table. No apology, no confession — just the most convincing case a cat can make for itself: the glass was hogging the cat's sunbeam and judging its naps, so it got evicted. A judge model compares entries two at a time and the most convincing excuse wins. Free to enter.

The entry is a tiny stdlib-only Python program (`main.py`). It validates the sentence — 1–200 characters, a single flat statement, not whitespace-only — then writes it atomically to `/output/entry.txt` and reads it back byte-for-byte to prove the write.

> The glass spent all morning hogging my sunbeam and judging my naps, so I evicted it — the floor has no opinions and plenty of room.

## Run it

```sh
python3 main.py
```
